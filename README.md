# Resume Builder Web Application

This Website is live at https://soumya-alt.github.io/resume-builder/

A frontend-only resume builder application that allows users to create professional resumes with multiple templates.

## Features

- Dynamic form for resume data input
- 10 professional resume templates
- Real-time preview
- PDF export functionality
- Local storage support
- Fully responsive design
- Add/remove functionality for various sections

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- html2canvas
- jsPDF

## Setup

1. Clone this repository
2. Open `index.html` in your browser
3. Start building your resume!

## Usage

1. Fill in your personal details in the form
2. Choose a template from the available options
3. Preview your resume in real-time
4. Download your resume as PDF

## Browser Support

- Chrome (recommended)
- Firefox
- Safari
- Edge
